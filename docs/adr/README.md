# Architecture decision records, Lantern SDK wrapper

Numbered, immutable once accepted. Superseding an ADR means writing a new one and linking both
ways. Reviews go to @northgate/cswt-architecture via CODEOWNERS (`/docs/adr/`); they are slow, plan
for it. The wiki mirror is the `CSWT-ARCH` space, search by number.

Format follows retail-web's ADRs: `Status / Date / Deciders / Tickets` headers, then
`Context / Options considered / Decision / Consequences`, dated addenda at the end.

| # | Title | Status | Date |
|---|---|---|---|
| 0001 | Angular 13 and Ivy partial compilation for `@northgate/lantern-sdk` 3.x | Proposed | 2026-09 |

Decisions made before this directory existed (View Engine retention under LNTN-361, the hosted
vendor script copy under GIS-1188) are recorded in `README.md` and were never written as ADRs.
